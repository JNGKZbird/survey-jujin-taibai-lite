# 测量学局劲工具（Survey Jujin）· 网页轻量版

测量学局劲工具（Survey Jujin）网页轻量版是面向土木类学生的纯静态测量记录与平差工具。七张表联动：表一→表三可联立（默认关闭）；表四、表六由表一推导，表五由表二推导，表G 由表一与表六带入。无需安装：用手机、平板或电脑的浏览器打开 `index.html`，或直接打开单文件 HTML；数据只保存在本机浏览器，原创代码采用木兰宽松许可证第 2 版（MulanPSL-2.0）。

桌面版（Windows，Tauri v2）：[survey-jujin-taibai](https://github.com/JNGKZbird/survey-jujin-taibai)

## 速览

- **七张表**：表一、表二、表三是记录表；表四、表五、表六是汇总与平差；表G 是导线计算表。
- **数据**：数据保存在本机浏览器的 `localStorage`，不上传；唯一可靠的备份是「导出全部项目」JSON。
- **许可**：原创代码采用木兰宽松许可证第 2 版（MulanPSL-2.0）；本版不含 AI 助手、联网搜索、第三方字体或公式库。
- **名字**：「局劲」是陕北话里的「厉害」。

## 能做什么

**记录。** 表一录全站仪导线观测，4 站/页；表二录三、四等水准（双面尺法），8 站/页，尺读数按米填；表三录角度与距离，6 站/页。三张记录表都能新增页，单表最多 100 页；支持多项目。

**联立。** 表一→表三可开启联立，默认关闭。开启后表三只读，按全局站号取表一的水平度盘读数与斜距，竖盘读数不进表三；解除后数值保留、可编辑。

**推导。** 表四由表一推导，表五由表二推导，表六由表一推导，表G 由表一与表六带入。表四、表五、表六正文不单独保存，打开时按来源表现算；表G 行数据会保存，带入后还能逐格改。

**检查。** 课程限差是默认值，可在界面里修改，不声称唯一口径。默认：2C ≤ 12″、指标差 ≤ 25″、水平角上/下半测回较差 ≤ 20″；表六对向较差可选 60√D、40√D、0.4×S，闭合差按 40√ΣD；表G 方位角闭合差按 fβ = 40″√n，全长相对闭合差按 K ≤ 1/4000。

**误差色。** 按允许误差倍数整格铺底：≤1× 不着色，1–2× 绿，2–3× 黄，>3× 红；边界值归较低一档。默认关闭，顶栏可开。表五与表G 不上色，表G 只在摘要卡比较 fβ 与 K。

**打印。** 每张表按 A4 版式（横向或纵向）排版，用浏览器打印对话框打印或另存为 PDF。打印跟随误差色开关；要印出底色，请在打印对话框勾选“背景图形”。

## 支持范围

| 表 | 内容 | 每页容量 | 数据来源 |
|---|---|---|---|
| 表一 | 全站仪导线观测记录表 | 4 站/页 | 手工录入 |
| 表二 | 三、四等水准测量记录、计算表（双面尺法） | 8 站/页 | 手工录入 |
| 表三 | 角度距离观测记录手簿 | 6 站/页 | 手工录入；或联立时取表一 |
| 表四 | 导线测量原始数据汇总 | 1 页 | 表一 |
| 表五 | 支水准测量原始数据汇总 | 8 人/页，每人 4 段 | 表二 |
| 表六 | 三角高程测量平差表 | 17 边/页 | 表一 |
| 表G | 导线计算表 | 11 行/页 | 表一 + 表六，可改 |

表四固定一页；其余各表最多 100 页。表四、表五、表六正文不单独保存，表G 行数据会保存、可改。表G 每页 11 行，一条导线可跨页续接；另起导线在选项里切换。

## 怎么打开

**目录版。** `index.html` 与 `assets/` 放在同一目录，双击 `index.html` 即可打开。`file://` 下不同浏览器对资源和存储的隔离规则不一致；想固定数据位置，建议用本地静态服务器指向这个目录，或使用托管方式。

**静态托管。** 仓库根目录就是静态站点。把根目录里的内容上传到 GitHub Pages、Gitee Pages 或任意静态服务器；仓库已带 `.nojekyll`。不要把整个目录再套一层，否则地址会多一级；保留 `LICENSE`。

**单文件版。** 构建后打开 `dist/测量学局劲-轻量版.html`，所有脚本、样式和许可证全文都在文件里，不需要 `assets/` 目录，也不会发起网络请求。适合作为一个附件发给同学。

手机和平板用浏览器打开托管地址最稳；单文件能否直接打开取决于系统与浏览器。表格按桌面宽度设计，窄屏需缩放或横向查看；正式打印建议用电脑。

## 数据与备份

数据保存在浏览器的 `localStorage` 里，按“来源（origin）”隔离；键名是 `survey-jujin.dev.v1`。刷新或重开浏览器，数据通常还在。清理站点数据、无痕模式、换浏览器或设备都会丢失数据；`file://` 下还可能按文件或目录隔离；`localStorage` 约 5 MB，写满后新改动无法保存（页面会提示）。页面第一次交互时会请求 `navigator.storage.persist()`，只能降低浏览器自动回收的概率，不能阻止手动清理。

**唯一可靠的备份是导出 JSON。** 项目菜单 →「导出全部项目」；恢复时用「导入」，或把 `.json` 文件直接拖进页面。首次打开会提示一次；如果超过 7 天没有导出，启动后会再提醒一次。

导入会自动识别单表、七表与全部项目。单表导入只替换目标表与该表设置，其余六表、联立映射、项目名不变；导入全部项目会整体替换项目库，确认框会先提醒备份。多个标签页同开时，另一页改写项目库，本页会提示刷新；两边不会自动合并，需同时看两份时请先导出。

`localStorage` 只是工作现场，不是备份。

## 与桌面版的差异

| 能力 | 网页轻量版 | 桌面版 |
|---|---|---|
| 七表、汇总、表G、联立、多项目 | 有 | 有 |
| JSON 导入导出、打印/PDF | 有 | 有 |
| 主题、误差色 | 有 | 有 |
| 数据保存 | 浏览器 `localStorage` | 本机 `store.json` + 备份 |
| AI 助手、联网搜索、识图 | 无 | 有 |
| 字体 | 系统字体 | 随包字体 |
| 原生备份目录 | 无 | 有 |

两版的七表结构与 JSON 文件格式兼容。网页轻量版是[主项目仓库](https://github.com/JNGKZbird/survey-jujin-taibai) `web/` 的构建产物，表格、计算与联立行为与桌面版同源；差别主要在存储、字体和 AI 助手。

## 单文件版

Release 已附带构建好的单文件版：[下载](https://github.com/JNGKZbird/survey-jujin-taibai-lite/releases/download/v0.1.0/survey-jujin-lite_0.1.0.html)，可直接下载或双击打开。

需要重新生成时（需 Node.js）：

```text
node tools/build-single.js
```

产物是 `dist/测量学局劲-轻量版.html`，脚本、样式和许可证全文都会内嵌。单文件版是构建产物，源码更新后请重新构建。

如果只拿到一个 HTML 附件，直接打开即可；数据仍然保存在浏览器里，换电脑前请先导出 JSON。

## 常见问题

### 手机上能用吗？

能。手机和平板浏览器打开托管地址即可；表格按 A4 宽度设计，窄屏需缩放或横向查看。

### 只填表一、表二够吗？

够。打开表一→表三联立后，表三自动取表一的数据；不开联立时表三手填即可。表四、表五、表六、表G 不用单独填。

### 数据存在哪？换电脑怎么办？

数据在本机浏览器的 `localStorage`，键名 `survey-jujin.dev.v1`，不上传。换电脑或浏览器前，用「导出全部项目」导出 JSON，再到新环境「导入」。

### 清理浏览器数据会怎样？

会丢。清理站点数据、用无痕模式、换浏览器或设备都可能让数据消失；浏览器在磁盘压力下也可能回收。请定期导出 JSON。

### 能打印或另存为 PDF 吗？

能。工具栏「打印」打开浏览器打印对话框，选择“另存为 PDF”即可。要印出误差色底色，请在打印对话框勾选“背景图形”。

### 导入单表会覆盖其他表吗？

不会。单表导入只替换目标表与该表设置，其余六表、联立映射、项目名不变；导入全部项目才整体替换项目库。联立时表一和表三不能单独导入。

### 会把数据传到网上吗？许可是什么？

不会。页面不向第三方服务器发送数据；目录版只从托管方加载自身静态资源，单文件版零外部请求。许可是木兰宽松许可证第 2 版（MulanPSL-2.0），完整文本见 `LICENSE`。

## 许可与维护

原创代码与文档采用木兰宽松许可证第 2 版（MulanPSL-2.0）；完整文本见 `LICENSE`。单文件版在文件头标注 SPDX，末尾嵌入许可证全文。本版不含第三方字体、公式库或其他第三方资源。

轻量版由主项目 `web/` 构建生成：主项目执行 `pnpm build:web` 生成 `dist-web/`，再执行 `pnpm sync:lite-repo` 同步到 `lite/`。日常修改请回主项目改源码；直接改 `index.html` 或 `assets/` 会在下次同步时被覆盖。单独 fork 后可按需要修改，不受这条同步流程限制。
